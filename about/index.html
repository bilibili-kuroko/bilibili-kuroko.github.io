VLM 后训练，细粒度内容理解。

我是欧阳，目前在哔哩哔哩担任高级算法工程师，从事安全业务与多模态算法工作。我的专长是 VLM 后训练与内容理解，推动模型在视频、图文、直播和社区等真实业务场景中落地。

我关注如何将模糊、依赖语境的安全规则，转化为模型可学习、可验证的能力。研究覆盖监督微调、强化学习、模型蒸馏与高质量数据构建，重点探索严重度排序、按需推理和可靠视觉问答。

从问题定义、实验验证到线上部署，我持续将业务中的关键问题沉淀为科研成果，已有多篇论文发表和多项专利相关成果，并参与获得 ICCV-CLVL 2025 Reliable VQA Challenge 第一名。

01严重度感知审核与自适应推理SFT + RL / Adaptive CoT / Severity-aware ranking
问题
隐含风险依赖细微元素组合与语境，二分类难以表达连续的风险程度；线上高吞吐又限制大模型推理开销。
方法
构建细粒度标签与严重度体系，通过 SFT + RL 训练排序能力；联合答案和过程奖励，引入 Adaptive CoT，并采用轻量召回与 VLM 排序两级架构。
产出
应用于社区与推荐安全治理，并将严重度排序、过度思考问题分别沉淀为第一作者和共同第一作者研究。
KUROKO 项目主页
02审核大模型与结构化取证Caption with Box / SFT + OPD / Grounded understanding
问题
通用模型缺少审核领域知识，需要同时解决风险覆盖、幻觉控制与证据输出稳定性问题。
方法
设计覆盖场景、主体、环境与细节的结构化取证模板，比较基础模型方案，结合 Caption with Box 微调与 OPD 蒸馏，增强定位能力和输出一致性。
产出
从零搭建审核取证能力、评估与迭代流程，让下游策略按需解析证据，推进内容理解与处置决策解耦。
03内容安全多标签重构与跨业务复用VLM classification / Joint loss / Long-tail learning
问题
定制化二分类将内容识别与业务处置规则耦合，模型难解释、难维护，也难在不同业务间复用。
方法
建立通用细粒度标签体系，在 VLM 微调时联合生成与分类目标，采用 Asymmetric Loss 和采样缓解长尾，并补充基于语言模型的文本风险分类。
产出
统一视频、封面、图文和社区等场景的基础识别能力，支持可调节的召回及处置策略，并提高失败案例的可归因性。
04图像检索与风险内容快速响应Fast-ReID / ArcFace / PFC / Louvain + DBSCAN
方法
将图像检索升级为召回与精排架构，结合对比学习、度量学习和 PFC 训练加速，利用 Louvain 与 DBSCAN 构建千万级训练数据。
落地
优化局部图和模糊图匹配，建立样本库质量控制与动态阈值机制，并探索 Chinese CLIP 文本检索图像以响应新风险类型。
05直播场景识别与大模型蒸馏Face detection / Classification / VLM → CV distillation
方法
优化未成年人和血腥暴力场景识别，结合人脸检测、分类及卡通识别处理不同输入形态，并将 VLM 分类能力蒸馏至轻量视觉模型。
落地
减少非目标内容误召，在直播吞吐约束下兼顾安全覆盖与审核效率，并复用于相关场景识别任务。
06水印台标检测与可控样本合成YOLO / 90+ classes / Configurable augmentation
方法
迭代 YOLO 检测方案，针对类别分散、标注不足，以及裁剪和模糊台标构建可配置的数据合成流水线。
落地
支持 90 余类水印台标识别，服务社区、视频、图文及版权相关业务，提升模型鲁棒性与扩类效率。
07数据生产引擎与可复用训练工具Human-in-the-loop / Caption & QA / vision-classification
数据
构建 Caption / QA 生成、人机协同细粒度标注和跨模型验证流程；通过可控合成与困难样本筛选响应线上数据分布变化。
工具
开发 vision-classification，集成骨干模型、损失、数据增强、自定义 Trainer、分类与蒸馏流程，沉淀离线评估和模型训练能力，减少重复工作。
